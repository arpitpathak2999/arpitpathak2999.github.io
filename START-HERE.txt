2) PUT IT ONLINE
----------------
FIRST create the empty repository on GitHub:

  a. Open  https://github.com/new
  b. Repository name — type exactly:   arpitpathak2999.github.io
  c. Choose Public
  d. Do NOT tick "Add a README file"
  e. Click "Create repository"

THEN double-click:  PUSH-TO-GITHUB.command

It will ask for:
  Username:  arpitpathak2999
  Password:  a Personal Access Token, NOT your account password
             (GitHub stopped accepting passwords for this in 2021)

Create the token at  https://github.com/settings/personal-access-tokens
  - Fine-grained token
  - Repository access: your new repository
  - Permissions:  Contents = Read & write
                  Workflows = Read & write
  - Expiration: 7 days is plenty

The token will be invisible while you paste it. That is normal — press Return.

If double-clicking is blocked by macOS, open Terminal and run these two lines:

  cd ~/Desktop/arpit-portfolio
  bash PUSH-TO-GITHUB.command

FINALLY, turn Pages on:

  1. Go to your repo -> Settings -> Pages
  2. Build and deployment -> Source -> choose "GitHub Actions"
  3. Wait about a minute

Your site:  https://arpitpathak2999.github.io
